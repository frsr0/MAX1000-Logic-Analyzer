# Hardware Screenshot Matrix

These screenshots were generated from the connected MAX1000 hardware UI on
2026-07-22. Each image selects one advertised mode/rate combination in the
Capture panel and records the resulting hardware-labelled controls.

This is UI-option coverage, not a claim that every screenshot performed a
physical acquisition. Physical capture validation is recorded separately in
the [hardware validation report](hardware-validation.md), including the
full-rate digital, narrow, analog, mixed, codec, and readback checks.

The exact-image physical MSO analogue proof is shown separately here:
[PMOD6→AIN4/ADC3 UART loopback](../../frontend/test-results/screenshots/mso-analog-uart-live.png).
